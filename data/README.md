# Synthetic data

Everything here is generated by `scripts/generate-data.mjs` with a fixed seed (`npm run generate-data`
writes the same files every time). The broker-dealer, desks, systems, symbols, customers, and
accounts are fictional ("Northwind Securities"). Schemas and error codes are simplified and
illustrative; they are not the official CAT or CAIS specifications.

| File | Rows | What it is |
| --- | --- | --- |
| `orders.csv` | 3,699 | Orders in the books, October 1 to 29, 2026 |
| `order_events.csv` | 13,747 | Reporting feed: NEW, ROUTE, DEST_NEW (the firm's ATS), MODIFY, CANCEL, EXECUTE events |
| `executions.csv` | 4,269 | Fills in the books |
| `cat_submissions.csv` | 13,747 | When each event was submitted (one file per trade date, due 08:00 ET the next trading day) |
| `cat_feedback.csv` | 89 | Regulator rejects with error codes LNK-01, SEQ-02, FLD-03, LTE-04 |
| `customer_records.csv`, `accounts.csv` | 504 | One customer record per account, as the books hold it |
| `cais_submissions.csv`, `cais_feedback.csv` | 504, 15 | The CAIS file of October 29 and its rejects (CA-11, CA-12, CA-13) |
| `daily_stats_history.csv` | 340 | Daily events and rejects per system, June to September, to train the anomaly model |
| `rules.csv`, `rules.json` | 6 | The rule library: what each pre-submission check tests, with a version |

The data set is frozen at a business clock of **October 30, 2026, 16:00 ET** (`RPT.CONFIG`), so
deadlines and countdowns read the same in Sample and Live mode. Rejects through trade date
October 27 start out repaired; the rest are open.

## Planted stories

On this synthetic data set:

1. **Linkage break from one desk.** From October 28 the ALGO-X system (Program Trading desk) drops
   the `PT-` prefix on the routed order ID it sends to the firm's own ATS, so the regulator can't
   link the route to the ATS's new-order event. Rejects spike on the October 29 file. Rule R-LNK-01.
2. **Clock drift.** From October 26 the OMS-B system (Options desk) stamps route and execution
   events about 1.4 seconds early on roughly a third of its orders, so they fall before the order's
   NEW event. Rule R-SEQ-02.
3. **Completeness.** On October 22 the MANUAL ticket system books 12 executions that never reach
   the reporting feed. The regulator can't reject what it never received, so only the
   books-to-CAT reconciliation (R-CMP-05) finds them.
4. **CAIS conflict.** Elena Marchetti holds three accounts whose records disagree on customer ID,
   date of birth, name, and address (CA-13). AI_SIMILARITY finds the three records, and the app
   proposes one canonical record for a person to approve.
5. **Volume anomaly.** October 16, a synthetic index-rebalance day, carries about three times
   normal volume. The anomaly model flags it on every system.

Background noise: a few invalid side codes (FLD-03), two late files (October 13 and 21),
postal codes that lost a leading zero, and large-trader accounts missing their ID.
